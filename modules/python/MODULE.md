## Instantiation notes

- The directory `files/src/{{PROJECT_NAME_SNAKE}}/` is renamed at instantiation
  (kebab-case project name → snake_case package name); `uv_build` expects exactly that
  module under `src/`.
- `[project].license` expects a valid SPDX expression — when the license decision is
  "TBD", `/new-project` removes the field instead of writing an invalid value.
- `uv.lock` is generated by `just setup` (`uv sync`) and committed; Renovate keeps it fresh.
- `target-version` for ruff is derived automatically from `requires-python`.
