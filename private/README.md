# private/

Everything in this directory except this README is **gitignored**. It holds operational
internals that must never reach the public tree: deployment specifics, personal notes,
source material with personal references, logs with real data.

Convention: living documentation (PROGRESS, REQUIREMENTS, specs) is always written free of
private information — names, customers, local paths, IPs. Anything that can't be phrased
neutrally goes here instead.
