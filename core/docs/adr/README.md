# Architecture Decision Records

Optional, lightweight (MADR-style). One file per durable architecture decision:
`NNNN-short-title.md`, numbered ascending — copy `0000-template.md` to start.

Rule of thumb: day-to-day decisions live in the `REQUIREMENTS.md` decision log or the
PROGRESS archive; an ADR is for choices that shape the system long-term (storage engine,
protocol, framework) and deserve their own page. Never rewrite an accepted ADR — supersede
it with a new one.
